## 📖 About

JetTransfer Travels is a full-stack travel booking platform that allows users to browse, book, and manage travel transfers. The system includes user authentication, booking management, real-time availability, and an admin panel for managing customers, drivers, and reservations.


---

## ✨ Features

### 👤 User Features
- 📝 User registration & login
- 🔍 Search and browse available transfers
- 📅 Book transfers with date/time selection
- 💳 Secure checkout process
- 📋 View booking history
- ✏️ Edit/Cancel bookings
- ⭐ Rate and review services

### 👑 Admin Features
- 📊 Admin dashboard with analytics
- 👥 Manage customers and drivers
- 🚗 Add/Edit/Delete transfer options
- 📅 Manage all bookings
- 💰 Track revenue and payments
- 📈 View reports and statistics

## 🚀 Getting Started

### Prerequisites
- Any web browser (Chrome, Firefox, Safari, Edge)
- Code editor (VS Code recommended)
- XAMPP installed (Apache + MySQL)

## 🐛 Known Issues

| Issue | Solution |
|-------|----------|
| Database connection fails | Check XAMPP is running and credentials are correct |
| Page not loading | Move project to htdocs folder |
| Session issues | Check PHP session configuration |
| Images not showing | Verify image paths are correct |
